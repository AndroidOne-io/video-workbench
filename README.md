# 剪辑工作台（video-workbench）

所有视频**共用**的东西都在这里：剪辑规矩、风格库、音乐音效、字体、通用代码。
每一期视频单独一个仓库（口播、素材、本期时间线代码、成片），剪完可以归档或删除，不影响这里。

## 给新对话的 Claude：开工顺序

1. 读 `剪辑规矩.md`（硬规矩，违反过都被严厉批评）。
2. 读这期要用的风格：`风格库/<风格名>/README.md`。**不用再逐帧看参考视频**，拆解都在里面。
3. 读这期视频仓库的 `README.md`（进度、本期特有的决定）。
4. 跑 `bash 工具代码/setup.sh`（需要转写口播就加 `--asr`），还原字体、音乐、模型路径。
5. 按「工作流程」一段一段剪。

## 工作方式（2026-10 起，阿亮定的）

- **每期视频做成一个网页**：浏览器里直接实时播放，不需要先渲染。**不用 Remotion**，用我们自己写的轻量网页引擎（纯 HTML + JS + Canvas，不依赖 npm，放在 `网页引擎/`）。
- **Claude 这边不渲染视频**，只做检查（用自带的 Chromium 打开网页，截关键帧自查：字有没有压脸、小圆窗挡没挡内容、有没有小字、画面和口播对不对得上）。检查完推代码。
- **阿亮预览**：拉代码后本地用浏览器打开；或者 Claude 直接给一个网页链接（手机也能看）。
- **最终成片阿亮在本地导出**（网页里的导出功能，或本地脚本逐帧导出）。
- 重效果（抠图、网点背景、金属字底图）提前用 Python 生成成图片，网页直接用。
- 鹈鹕测试是用旧的 Python 方式做的，保持原样；`工具代码/` 里的 Python 效果是搬到网页组件时的参考。

## 工作流程（鹈鹕测试里摸索出来的）

1. **转写口播**：sherpa-onnx SenseVoice 出带时间的句子；关键词需要逐字时间戳时，把那一句单独切出来再识别一次（输出里有每个字的时间）。校对后存成字幕源 json。
2. **定方案**：对照分镜和口播，每一句定画面。先出几张效果图（静帧）给阿亮看方向。
3. **一段一段做**（30–45 秒一段）：写这一段的场景 → 渲染几张关键时间点的静帧拼成一张图自查（字有没有压脸、小圆窗挡没挡内容、有没有小字）→ 再渲染视频。
4. **配乐**：每个段落一首，口播停顿处抬升 + 重击；空灵的曲子只给空镜。
5. **混音**：整片从头混（人声分段会自动做淡入淡出），-14 LUFS。
6. **交付**：小于 30 MB 直接发给阿亮；大文件推到这期的仓库。阿亮提的问题，补进 `剪辑规矩.md`。
7. **大文件**：单个文件必须小于 100 MB。云端的 Claude 推不了 Git LFS（上传地址被网络拦截），所以直接用普通 Git；成片只留最终版。
