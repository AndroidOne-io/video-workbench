# 风格：小Lin说（参考）→ 我们的变体「鹈鹕考场」

参考视频：`小Lin说.mp4`（834 秒）。**不用再逐帧看**，拆解都在这个文件夹里。

学的是她的包装方式和节奏，**不是一帧一帧地抄**。目标：达到她 90% 的质感，但一看就是我们自己的风格。

## 一、小Lin说的精华

- **角色徽章**：故事里每个人、每家公司都做成圆形徽章，全片反复登场；人物徽章两侧写书法外号（大卫、姐姐、老爹）。
- **反复回来的舞台**：同一张信息图出现多次，每次状态变化（变灰、盖章、变色、汇合）。
- **大字只在口播停顿时单独出现**，三种：
  - 银色金属字（「最大收购案」，上下可带一行小前提）
  - 粗毛笔飞白字（「大道至简」「文娱帝国」，可带故障闪）
  - 大数字（「$810亿」）
- **截图处理**：铺满 → 透视倾斜 → 甩镜模糊进场 → 其余变淡 → 重点句高亮扫过 → 人物侧边带渐变压入。（她有中文翻译小字，**我们不要**。）
- **图表**：平放进场 → 倾斜成透视 → 大数字砸上 → 镜头推到重点。
- **背景**：深蓝灰 #151A25–#1A1F2C 或深紫，叠同心圆、网格、布纹，或垫压暗的相关大图（人物照片加网点）。
- **徽章**：半透明磨砂玻璃，细亮边，文字浅色半透明；选中的亮，其余变灰。

## 二、实测数据（`数据_` 开头的文件）

- 主播全屏只占 29%，单次中位 4.2 秒。
- 画面平均每 1.3 秒有变化（每分钟 47 次），不动的最长约 8 秒。
- 语速 371 字/分；口播中每分钟 2–3 个 1 秒以上的停顿。
- 音乐（音源分离后）：口播一停，音乐抬高 15–25 dB 配重击；每分钟约 7 次低频冲击，对齐大字、盖章、数字；重击前音乐常完全停一下；按段落换曲；整片 -14 LUFS。

文件：`小Lin说_转写.txt`（带时间转写）、`cuts2.txt`（镜头切点）、`s2_rhythm.json`（节奏统计）、`s2_music_an.json`（音乐分析）。

## 三、我们的变体「鹈鹕考场」（阿亮认可的方向）

- **配色**：夜蓝黑底；**鹈鹕橙** #FF8A2A 是标志色，**电光青** #4ED6E8 做辅色，**红笔红** #E84034 用来批改。
- **背景**：矢量绘图网格（点阵 + 带锚点和控制柄的贝塞尔曲线）+ 橙青光晕。
- **徽章**：半透明玻璃 + 橙色「选中框」（四角锚点方块）。
- **角色徽章**：深色圆盘 + 抠图主体在下半部 + 外号大字（杨任东竹石体）在两侧。
- **结论用红笔批改**：画圈、打叉、「0分」、「交白卷」「通过」「降智」印章。
- **大标题**：
  - 金属拉丝（优设标题黑）+ 扫光 + 微光，背景是橙青粒子隧道 + 模糊大字景深；
  - 或粗毛笔（庞门正道粗书体）+ 网点化的素材背景 + 故障闪进场。
- **字幕**：得意黑斜体白字细黑边，底部居中。
- **贴纸**：emoji 白边贴纸（🚲🐔🎁🥴🎉😂🧠💡），在主播出镜时弹在两侧。
