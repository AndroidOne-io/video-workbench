## 配乐_科技解说/（阿亮新加的 14 首，还没逐首听过）

文件名看是科技解说、纪录片悬疑、希望钢琴、马林巴企业风等，适合科技类口播的垫乐。用之前先测响度曲线找起点。

## 音效/

| 音效 | 用法 |
| --- | --- |
| 转场-Whoosh | 每次切画面、卡片甩进来，峰值对齐切点 |
| 转场-Windy swish | 更软的转场 |
| 上升-whoosh rise | 大标题前的蓄力，**结尾**对齐标题那一帧 |
| 上声音-reverse rise | 反向吸气式蓄力 |
| 重音-Thud Hit C | 大标题、大数字的重击 |
| 重音-咚 重磅 | 更沉的重击，和 Thud 叠用 |
| 重音-Gate Hit | 盖章、戳破泡泡 |

另有代码合成的小音效（`工具代码/synthfx.py`）：shine（闪光）、scribble（红笔划）、pop（弹出）、type（打字）。
